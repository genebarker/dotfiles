---
description: End-of-session retrospective - keep/lose/try, then prune memory
---

Run the session wrap:

1. **Reflect** - 3 bullets, honest not generous:
   - Keep: what worked, worth repeating
   - Lose: what went wrong, worth correcting
   - Try: an experiment for next session

2. **Write** the keepers to memory. Keep/Lose become feedback memories,
   Try becomes a project memory. Skip anything Gene would naturally
   correct in conversation - if it can be reconstructed from the data on
   demand, it doesn't need storage.

3. **Prune.** This beat fires every time, independent of whether anything
   went wrong - success retires memories at the same rate as failure.
   Scan MEMORY.md for:
   - work that shipped this session; git and `gh issue` are the record
   - status claims this session disproved (issue closed, branch merged)
   - anything a new CLAUDE.md clause now covers

   Delete those, repair `[[links]]` that pointed at them (inline the
   content where a link was load-bearing), then rewrite the index.

4. **Flag** any CLAUDE.md amendment worth making - propose, don't write.

Partners who enjoy working together do better work; this ritual is how
that compounds instead of resetting each session.
